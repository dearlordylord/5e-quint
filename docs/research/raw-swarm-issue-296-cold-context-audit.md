## Executable-plan result

Without path hints, the agent produced the required operator sequence:

1. Configure one `availableOnly` and `supportedOnly` Campaign with two to four
   bounded iterations and four complete candidates per iteration.
2. Compare every selected Candidate with every admitted Scenario, name closest
   matches and material differentiators, revise nonempty critiques, and retain
   rejection rather than promoting redundancy.
3. Keep generation, the five independently scoped Scenario-review assessments,
   neutral setup authoring, delegated setup control, player execution, and
   post-play review in their documented roles.
4. Commit the admitted bundle, zero-sheet character source, and setup source at
   their clean-revision boundaries.
5. Attempt two executions with the same Scenario identity and distinct
   Execution/Evidence Set identities.
6. Replay each exact transcript, independently review each bounded audit packet,
   import review results, resolve promoted issue fingerprints, and finalize
   immutable findings.
7. Retain candidate, authoring, setup, player, replay, or review obstructions
   precisely instead of substituting content or fabricating support.

The plan correctly treated the catalogue as an identity/integrity authority,
not a semantic-duplicate detector, and assigned the final admission comparison
to the operator protocol.
