# Level 20 mining automation: Survey contract

Research baseline: the "What exists" and "Extension slices" sections below
describe the pre-extension state and the work chosen from it. The extension is
now implemented: mining audits cover frontiers 7–20, source preflight checks
the class, spell, character-creation, and feat files, and class-specific spell
access is derived through spell level 9. The remaining semantic classification
is the subagent-powered Survey decision described below.

Decision: **put mining inside each automated Survey**, with a one-time extension and calibration of the existing generator. The machine produces a source-backed denominator and checks its structure; agents review semantic omissions and classify owner pressure. Neither action proves runtime support. This matches the current inventory's separate denominator and the mining audit's separate support snapshot. [Inventory owner](../../plans/unit-profile-coverage/README.md#srd-unit-inventory), [audit projection](../../scripts/level1-7-mining-audit-report.cjs#L68-L106).

## What exists

- `unit-profile-coverage-check.cjs` discovers installed/authored Units, builds and validates the SRD inventory, and writes or compares mining audit artifacts. Audits are generated for character frontiers 7–12; the self-test asserts that exact list. [CLI](../../scripts/unit-profile-coverage-check.cjs#L259-L297), [audit output](../../scripts/unit-profile-coverage-check.cjs#L577-L595), [frontiers](../../scripts/mining-audit-frontiers.cjs#L1-L13), [self-test](../../scripts/unit-profile-coverage-self-test.cjs#L1224-L1244).
- The generator reads the local `classes.md`, selects all twelve class sections, extracts class table rows, dedicated level headings, repeated feature grants, progression deltas, and class spell-list rows with source line references. It joins authored JSON, installed SRD ids, claims and owner evidence into distinct dispositions. [Source/sections](../../scripts/srd-unit-inventory.cjs#L11-L25), [extraction](../../scripts/srd-unit-inventory.cjs#L2527-L2757), [join](../../scripts/srd-unit-inventory.cjs#L5201-L5229). The audit projects row presence separately from support and counts character-level and spell-level bands separately. [Audit](../../scripts/level1-7-mining-audit-report.cjs#L68-L106), [bands/metrics](../../scripts/level1-7-mining-audit-report.cjs#L205-L274).
- Current limits are explicit: class feature range and spell access are capped at character level 12; spell lists stop at spell level 6; validation has fixed counts for levels 5–12 and level-6 spells, plus hand-recorded progression signatures for 8–12. [Level cap](../../scripts/srd-unit-inventory.cjs#L112-L145), [spell cap](../../scripts/srd-unit-inventory.cjs#L611-L651), [reachability](../../scripts/srd-unit-inventory.cjs#L1170-L1181), [expected counts](../../scripts/srd-unit-inventory.cjs#L5864-L5896), [signatures](../../scripts/srd-unit-inventory.cjs#L6096-L6108). These expectations are reviewed fixtures, not discovered proof of completeness.
- Semantic closures and follow-up text are partly hand-authored in the generator: named feature owner maps, spell missing-classification maps, and recommended delivery batches. Their presence does not make a new frontier automatically classified. [Owner maps](../../scripts/srd-unit-inventory.cjs#L117-L127), [spell classifications](../../scripts/srd-unit-inventory.cjs#L708-L730), [batches](../../scripts/srd-unit-inventory.cjs#L5184-L5199). The existing checker can reject unreviewed authored, uninstalled spell rows and generic class progression dispositions. [Spell review](../../scripts/srd-unit-inventory.cjs#L5660-L5684), [progression review](../../scripts/srd-unit-inventory.cjs#L6177-L6195).

## Required Survey output through level 20

1. A reproducible inventory keyed by class, class level, row kind and source span: all twelve class tables at levels 1–20; class and subclass feature grants, repeated grants, feature replacements or upgrades, choices and spell access; every changed class-table column; class-list spell pressure at levels 0–9 where that **class's** rules grant access. Distinguish class level, total character level and spell level. The current extractor and per-class slot test provide a starting point. [Extractor](../../scripts/srd-unit-inventory.cjs#L2616-L2794), [slot test](../../scripts/srd-unit-inventory.cjs#L1140-L1168), [multiclass distinction](../../.references/srd-5.2.1/character-creation.md#L887-L895), [spell preparation/slots](../../.references/srd-5.2.1/character-creation.md#L927-L949).
2. Explicit cross-chapter pressure and trace links when a class row points outside `classes.md` (for example level-19 feat choice and prerequisites, advancement/multiclass rules). A `classes.md` row alone cannot close these choices. [Level-19 grant](../../.references/srd-5.2.1/classes.md#L341-L345), [feat prerequisites](../../.references/srd-5.2.1/feats.md#L109-L123), [advancement](../../.references/srd-5.2.1/character-creation.md#L806-L810), [multiclass features](../../.references/srd-5.2.1/character-creation.md#L911-L949).
3. A machine-readable completeness result before classification: source paths and digests; expected and observed class sections, all 20 table rows per class, heading/table agreement, spell-list sections, source ranges, duplicate ids, and known exceptions. Missing or unparsed data is `unresolved`, never a zero count. The existing `tableRows` and `headingLine` return `[]`/`undefined` for absent matches, so new validation must catch silent parser misses. [Parser](../../scripts/srd-unit-inventory.cjs#L962-L1031), [class section check](../../scripts/srd-unit-inventory.cjs#L2527-L2549), [current validator](../../scripts/srd-unit-inventory.cjs#L5542-L5555). The audit already reports zero-row bands as `missingMinedLevelBands`, but that cannot detect a missing row inside a nonempty band. [Audit metric](../../scripts/level1-7-mining-audit-report.cjs#L205-L239).
4. A separate agent-reviewed classification for each new mechanic or ambiguity: source span, classification, owning layer, reason and unresolved question. Check choices, replacements, subclass ownership, spell access, and interaction with multiclassing; require the orchestrator to check anchors before changing workflow state. This is needed because table deltas only record changed cells, while RAW can change behavior in a feature paragraph (for example Warlock Mystic Arcanum replacement on each Warlock level). [Delta algorithm](../../scripts/srd-unit-inventory.cjs#L2443-L2477), [Arcanum RAW](../../.references/srd-5.2.1/classes.md#L9016-L9024), [workflow decision](../agents/level-20-workflow-preparation.md#state-and-routing).

## Extension slices and checks

1. Extend range/config and output bands to 13–20, then source parser and completeness validation before producing accepted artifacts. Add spell levels 7–9 with class-specific access. Warlock's level-7/8/9 spells come from Mystic Arcanum at class levels 13/15/17, while its Pact Magic slot level stays 5; the current slot-only reachability test would omit those rows. [Frontier config](../../scripts/mining-audit-frontiers.cjs#L1-L10), [slot-only test](../../scripts/srd-unit-inventory.cjs#L1156-L1168), [Warlock table](../../.references/srd-5.2.1/classes.md#L8879-L8927), [Arcanum text](../../.references/srd-5.2.1/classes.md#L9016-L9024).
2. Add reviewed expected counts/signatures and explicit special-case invariants for each new level; preserve source-span references and repeated-feature links. Then update audit rendering/metrics, which currently enumerate only spell levels 3–6. [Current validation](../../scripts/srd-unit-inventory.cjs#L5864-L5896), [repeat links](../../scripts/srd-unit-inventory.cjs#L2653-L2688), [audit spell bands](../../scripts/level1-7-mining-audit-report.cjs#L128-L135).
3. Focused verification: self-test each new frontier/band and negative fixtures for deleted table rows, missing spell-list sections, malformed/truncated table markup, absent class section, duplicate source rows, and Warlock Arcanum access; then run `pnpm unit-profile-coverage:check --write` and `pnpm unit-profile-coverage:check` for the generated artifacts. The existing self-test covers exact frontier list, audit/support separation and one unreviewed-spell rejection; extend those checks rather than treating generation success as completeness. [Self-test](../../scripts/unit-profile-coverage-self-test.cjs#L1189-L1244), [spell rejection fixture](../../scripts/unit-profile-coverage-self-test.cjs#L3741-L3765), [documented commands](../../plans/unit-profile-coverage/README.md#L434-L450).

**Stop condition:** if a bounded hidden/ignored search for an expected RAW passage fails, inspect the likely local corpus file directly; if either read fails, output is truncated, or the passage remains absent after both checks, mark the evidence unresolved and stop rather than infer absence or browse another rules source. The project mandates this workflow. [Repository rule](../../AGENTS.md#rules-and-formal-models). For parser failure, reject the Survey artifact before support classification; the present parser's empty returns make this a concrete risk. [Parser](../../scripts/srd-unit-inventory.cjs#L962-L1031).

**Boundary:** inventory closure means source-backed scope has been enumerated and classified. It does not mean the authored record is installed, has a supported profile, or is executable. Those are separate fields and evidence gates, and the later-level mining audits are non-blocking until explicitly promoted. [Inventory definition](../../plans/unit-profile-coverage/README.md#L409-L439), [audit support snapshots](../../scripts/level1-7-mining-audit-report.cjs#L68-L106), [matrix gate](../../plans/unit-profile-coverage/README.md#L424-L432).

**Scope decision:** Survey covers all relevant level-gated SRD options across the corpus. Keep class/class-list rows in the existing Unit inventory; use the RAW coverage matrix as the owner for other chapters, and link dependent choices such as level-19 feats and multiclass rules to those spans. Survey must check both for omissions; it must not duplicate cross-chapter rules as invented class rows. [Current inventory scope](../../plans/unit-profile-coverage/README.md#srd-unit-inventory), [level-19 feat grant](../../.references/srd-5.2.1/classes.md#L341-L345), [RAW coverage owner](../../plans/raw-coverage/README.md#raw-coverage-matrix), [domain-document ownership](../../CONTEXT-MAP.md#related-authorities).
