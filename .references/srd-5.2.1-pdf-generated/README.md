# PDF-generated SRD 5.2.1 candidate

The fourteen Markdown files and `.source-map.json` in this directory were
generated solely from the checked-in official
[`SRD_CC_v5.2.1.pdf`](../SRD_CC_v5.2.1.pdf). They are versioned candidate
artifacts, not the project's working RAW source. Existing consumers still use
the [corrected conversion](../srd-5.2.1/), while the historical coverage
attestations apply to the [pre-migration corpus](../srd-5.2.1-reviewed/).
These must be reconciled and migrated in
[issue #543](https://github.com/dearlordylord/5e-quint/issues/543).

Do not edit generated files by hand. Run `pnpm srd:generate` to regenerate an
ignored scratch copy and `pnpm srd:autoresearch:check` to verify source
identity, page accounting, and deterministic output. The generator and its
evaluator are documented in
[`scripts/srd521/README.md`](../../scripts/srd521/README.md).

The candidate is not yet shown to be textually superior to the pinned
Downfallx conversion. See the
[direct comparison](../../docs/research/srd-5.2.1-downfallx-comparison.md)
before making such a claim.
