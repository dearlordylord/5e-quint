# SRD 5.2.1 Markdown corpus

This directory is the project's current working RAW text for rule and content
consumers. It is a corrected Markdown rendering whose conversion input was
[`downfallx/dnd-5e-srd-markdown`](https://github.com/downfallx/dnd-5e-srd-markdown)
at commit `1b4b99dcb786cdd1a2fb26f8acec1551191f1ca4`. The conversion is input
material, not RAW provenance or authority.

Current RAW review and validation use the Markdown files in this directory
directly. The sibling official PDF is retained as an optional secondary
reference for a concrete ambiguity that Markdown review cannot resolve; it is
not a routine review input or acceptance gate. Its SHA-256 digest is
`8974902d109d6e63672d7c490bde9ccf052410503d9cfa768237154fbc5e3d87`.

This Markdown corpus is adapted from the community-maintained
[`downfallx/dnd-5e-srd-markdown` conversion](https://github.com/downfallx/dnd-5e-srd-markdown/blob/1b4b99dcb786cdd1a2fb26f8acec1551191f1ca4/README.md)
at the pinned commit above. We changed its layout and corrected text and tables
during corpus preparation. The pinned conversion is input material, not RAW
provenance or authority. Focused rule reviews use the checked-in Markdown
directly; an identified PDF lookup may be recorded only as optional secondary
evidence. The conversion and this project are not official
Wizards publications.
[attribution.md](attribution.md) records the pinned conversion input, and
[NOTICE](../../NOTICE) carries the repository-level SRD notice.

The historical RAW coverage attestations belong to the byte-preserved
pre-migration corpus in
[`../srd-5.2.1-reviewed/`](../srd-5.2.1-reviewed/), not this
later layout. They are retained as research evidence. Rules work cites passages
in the current Markdown directly and verifies the focused implementation;
whole-corpus review migration is not a prerequisite. The
[comparison report](../../docs/research/srd-5.2.1-downfallx-comparison.md)
records historical corpus-comparison findings and their limits.
