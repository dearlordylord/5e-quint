# D&D Rules Q&A Research Tools

The community Q&A corpus download, parsing, and classification scripts are
research tools. They are not a rules source, provenance source, or verification
lane. Active verification lives with focused package QNT, rule-core QNT, parity
witnesses, and runtime tests.

## Current Commands

Corpus classification is still usable when the private corpus exists:

```bash
python3 scripts/qa/classify.py --limit 100 --source se --workers 5
```

## Authored-Identity Boundary

Community posts, Sage Advice pages, D&D Beyond pages, and other downloaded data
are structured research input only. They are not provenance for shipped or
materialized rules content and must not be copied into publishable source.
