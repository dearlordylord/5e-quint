# 5.5e SRD Oracle

Explore the installed redistributable 5.5e SRD catalog, create characters, and
play rules-backed battles. Catalog browsing and complete guest journeys work
without sign-in. The agent retains the temporary session handle and tells you
when a session is not saved.

Standard MCP OAuth is used only when you choose to save, list, resume, or
permanently delete account-owned Play Sessions. Never provide the agent with a
password, API key, bearer token, or unrelated machine permission.

The package contains a focused Skill and points to the publisher's Universal
HTTPS MCP endpoint. It uses only the project's redistributable SRD corpus and
visibly synthetic content; it does not provide or execute closed-license PHB+
content.
