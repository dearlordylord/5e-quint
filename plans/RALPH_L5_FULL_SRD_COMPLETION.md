## Scope

This file is the Ralph launch queue for level-5 full SRD completion after the
pre-work audit in
`plans/unit-profile-coverage/L5_FULL_SRD_REACHABLE_UNIT_ACCOUNTING.md`.
Generic level-5 progression deltas are audited in
`plans/unit-profile-coverage/L5_PROGRESSION_DELTA_AUDIT.md`.

It does not reopen the older L5 Surface/runtime lanes. Those lane files are
done and are historical implementation records. This queue owns the remaining
SDK RAW integration and SDK-scope closure work for the 138 row frontier.

## Ralph Task-Base Check

Every Ralph task must run the task-base check before research or edits:

1. Log the task-provided Base SHA or Base ref.
2. Log `HEAD`.
3. Run `git merge-base --is-ancestor <Base SHA> HEAD`.
4. Stop and report a branch-base mismatch if the ancestor check fails. Do not
   rebase or repair branch state inside the task.

## Lane Rules

- Use only local SRD 5.2.1 sources.
- Do not browse external rules sources.
- Do not add PHB+ authored identity.
- Do not implement broad runtime behavior from this plan unless a task
  explicitly asks for an SDK scenario against already-supported behavior.
- If a task finds that SDK work requires a missing durable owner, record or
  preserve a future-owner-before-SDK closure instead of adding an adapter.
- Runtime semantics must be admitted by typed Surface/procedure facts and
  explicit runtime state, not spell or feature ids.
- Do not run MBT for this queue unless a later implementation task changes
  battle-runtime behavior and explicitly reaches end-to-end validation.
