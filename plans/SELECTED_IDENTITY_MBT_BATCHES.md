# Selected Identity MBT Batches

Goal: raise selected identity MBT coverage with small, diagnosable batches for
already-supported Unit identities. Do not use broad exploratory MBT. Each batch
should add checker-visible `selected-identity-mbt` evidence, focused replay
coverage, and refreshed coverage artifacts.

## Batch 1 - Mastery Properties

- `mastery_cleave`
- `mastery_sap`
- `mastery_topple`

Reason: stateful combat features with target, attack, damage, save, and timing
pressure.

## Batch 2 - Reaction / Interruption

- `shield`
- `hellish_rebuke`
- `bard_cutting_words`
- `monk_deflect_attacks`

Reason: trigger timing, resource spending, reaction ownership, and roll/damage
mutation.

## Batch 3 - Condition Save / Repeat Save

- `color_spray`
- `entangle`
- `hideous_laughter`
- `sleep`

Reason: conditions, duration cleanup, repeat-save lifecycle, and spell-owned
state.

## Batch 4 - Healing / Stabilization

- `cure_wounds`
- `healing_word`
- `paladin_lay_on_hands`
- `spare_the_dying`
- later: `mass_cure_wounds`, `mass_healing_word`
