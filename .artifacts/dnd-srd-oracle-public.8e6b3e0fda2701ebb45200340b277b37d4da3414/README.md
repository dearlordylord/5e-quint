# 5.5e SRD Oracle

Explore the installed redistributable 5.5e SRD catalog, create characters, and
play rules-backed battles. Catalog browsing works without sign-in. Hosted
character and battle sessions require standard MCP OAuth and are saved to the
connected account by default.

Never provide the agent with a password, API key, bearer token, or unrelated
machine permission; authorization is completed through the client-managed OAuth
flow.

The package contains a focused Skill and points to the publisher's Universal
HTTPS MCP endpoint. It uses only the project's redistributable SRD corpus and
visibly synthetic content; it does not provide or execute closed-license PHB+
content.
