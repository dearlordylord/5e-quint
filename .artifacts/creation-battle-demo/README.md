# Creation + battle demo

`creation-battle-demo.mp4` is a 46-second, 1280×720 recording of an explicitly
labeled demo client. Its presentation data was captured from the repository's
real `@dnd/mcp` server through an in-memory MCP transport.

The recorded run created and finalized an Orc Soldier Fighter, admitted that
same Character Session to battle against the SRD Goblin Warrior, discovered the
Fighter's available acts, supplied a Longsword target and rolls, and displayed
the runtime checkpoint changing the Goblin from 10 HP to 2 HP.

The video contains no credentials, authorization codes, Play Session handles,
or personal account data. It demonstrates local MCP execution through a demo
client; it does not claim to show an established chat-product integration.
